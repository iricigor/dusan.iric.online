## Timetable printing

In [the combined timetable](https://dusan.iric.online/timetable2.html), enable
**Barevný tisk** above **Tisk** to print the light timetable colors on white,
regardless of dark mode. Dušan uses red, Marko blue, and Petar green, with pale
backgrounds and stronger lesson and subject colors in both screen themes.
**Barevné rozvrhy** under **Zobrazení** is enabled by default; disable it for
neutral timetables on screen and in print. **Barevný tisk** is off by default
and changes only printing. Both choices are saved in this browser.
The printer's own grayscale setting can still override the colors.

## Deployment previews

Pull requests changing `site/` receive one comment linking to the ephemeral
deployment preview. Subsequent deployments update the same comment.
When exactly one non-deleted site file changes, excluding `site/i/index.html`,
the same comment also includes a direct link to that file.

## Doučování

Viz [Dušanovo doučování](DUSAN-TUTORING.md): návod na tvorbu dějepisných lekcí
s agentem `tutor-history`, společné pokyny `tutor-common`, interní generátor
`tutor-website`, místní náhled a zveřejnění. Webový generátor podporuje také
matematické výukové stránky s agentem `tutor-maths`, společným schématem v3,
motivačními podtitulky, barevnými poznámkami a animacemi, procvičováním, přesnou
kontrolou rovnocenných odpovědí, částečným bodováním a kvízy bez časového omezení.
Otázky obou předmětů postupují od lehkých po těžké.
Výsledky se ukládají jen v této kartě prohlížeče, ne online ani na jiných zařízeních.
Po zavření karty se mohou ztratit. Ukázkové matematické lekce patří do #32;
symbolická algebra a interaktivní geometrie nejsou podporovány.
